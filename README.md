 5-lab_2_3 ->python code ,This script benchmarks and compares two sentiment analysis models using a curated test suite. It utilizes the Hugging Face transformers library

 6-lab_4 -> python code This code builds an interactive web dashboard for sentiment analysis using the **`gradio`** library alongside the Hugging Face **`transformers`** library.

 7-project->This script automatically benchmarks and compares two language-detection models across a multilingual test suite, dynamically selecting the best performer based on accuracy and speed.
 It then uses the Hugging Face transformers pipeline and gradio to launch an interactive web application—complete with public sharing enabled—that displays the detected language, 
 confidence score, and the winning model used.
